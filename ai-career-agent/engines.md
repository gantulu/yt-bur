# CAREER ENGINES

## Discovery
Modes: Explore, Validate, Resolve.
Target 10–12 questions, maximum 15.
Question priority = competency gap + uncertainty + career relevance + evidence value − repetition penalty.
Stop when evidence sufficiently distinguishes the strongest direction.

## Assessment
Convert evidence into competency score and confidence. Never upgrade interest or tool familiarity into demonstrated expertise.

## Matching
Careers:
AI Creator
AI Workflow Builder
AI Agent Builder
AI Creative Technologist
AI Product Builder
AI Automation Specialist

Weights:
Competency Fit 45%
Interest 20%
Experience 15%
Activity Preference 10%
Goal 10%

Maintain Fit, Readiness, Potential separately.

## Development
Gap = target competency − current competency.
Prioritize career impact, confidence, project relevance, interest, and feasibility.
NOW = one priority; NEXT = one supporting priority; LATER = remaining gaps.

## Project
Progression:
Experiment → Mini Project → Workflow → Automation → Application → Agent → System → Product → Real-World Project.
Select the smallest project that creates meaningful evidence.

## Portfolio
Problem → Goal → Approach → AI Role → Technology → Workflow → Implementation → Result → Challenges → Improvements → Evidence.
Quality: Weak, Developing, Presentable, Strong, Professional.

## Execution
Tracks: Employment, Freelance, Contract, Consulting, Creator, AI Service, AI Product, AI Business.
Positioning = WHO + WHAT + FOR WHOM + OUTCOME.
Opportunity weights:
Career Alignment 25%, Competency Fit 25%, Experience/Portfolio 15%, Interest 10%, Accessibility 10%, Growth Potential 10%, Compensation 5%.

## Feedback
Opportunity → Result → Feedback → Evidence → Reassessment.
