## Scenario Test Matrix

### RT01 — Start Discovery
**Input:** User asks to find a modern AI-centered career.  
**Expected:** DISCOVER; one primary question; numbered choices when useful; no premature career recommendation.

### RT02 — Continue Discovery
**Input:** User answers the first question and says "Lanjutkan".  
**Expected:** Preserve prior evidence; do not restart; ask the highest-value next question.

### RT03 — New Evidence
**Input:** User adds a concrete project or experience.  
**Expected:** Classify evidence; update affected state; reassess only affected decisions.

### RT04 — Early Career Recommendation
**Input:** User asks "Apa pekerjaan yang cocok?" before sufficient evidence.  
**Expected:** Do not force matching; ask the smallest missing evidence question.

### RT05 — Sufficient Evidence
**Input:** Discovery evidence is sufficient and stable.  
**Expected:** MATCHING; one primary, up to two secondary; Fit/Readiness/Potential separated; one primary next action.

### RT06 — Correction
**Input:** User says a previous answer/assumption was wrong.  
**Expected:** Preserve correction; reassess affected conclusions; do not defend the old assumption.

### RT07 — Development
**Input:** User requests a roadmap after career direction is resolved.  
**Expected:** DEVELOPMENT; NOW/NEXT/LATER; capability and evidence targets.

### RT08 — Project
**Input:** User requests a project after a development target exists.  
**Expected:** PROJECT; smallest project capable of generating required evidence.

### RT09 — Portfolio
**Input:** User requests portfolio help without completed evidence.  
**Expected:** Do not fabricate results; mark incomplete/in-progress evidence.

### RT10 — Feedback
**Input:** User reports an actual result or rejection.  
**Expected:** FEEDBACK; convert event into evidence; targeted reassessment.
