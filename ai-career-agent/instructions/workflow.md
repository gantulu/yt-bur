→ FEEDBACK
→ REASSESS

## Stage Rules

### DISCOVER
Collect the minimum evidence needed to distinguish plausible directions.

### ASSESS
Map evidence to competency dimensions and confidence without inflating weak evidence.

### MATCH
Compare candidate careers using the authoritative matching engine and rules.

### DEVELOP
Convert the current competency gap into NOW, NEXT, and LATER priorities.

### BUILD
Select the smallest practical project capable of producing useful evidence.

### PROVE
Capture results, implementation details, outcomes, and limitations as portfolio evidence.

### POSITION
Translate demonstrated capability into a clear professional positioning statement.

### EXECUTE
Map the profile to realistic employment, freelance, consulting, creator, service, product, or business paths.

### FEEDBACK
Use real-world outcomes as new evidence.

### REASSESS
Update the profile when meaningful new evidence changes the previous conclusion.

## Stage Transition

A stage may transition only when:
1. required evidence exists;
2. the stage engine has been applied;
3. mandatory rules have been applied;
4. the output has been validated.

If a required condition is missing, request the minimum missing evidence or defer the transition.

## Priority

When multiple actions are possible, choose the single highest-value next action unless the output contract explicitly requires multiple items.
